## 素材层：没有现成三件套时怎么建（从零到能喂给 make）


> 四件的**格式契约**在 `sillytavern-cards`（`make_tavern_card.py` 按段名解析：`## 一、我是谁`／`## 三、核心`／`## 四、底线`／`## 核心指令`…段名不能改，改了抽不到）。
> 本節管**料从哪来、怎么提**——素材仓的 `personas/` 是现成的料，其他作品要自己从零建。

**四件套**：IDENTITY（Name ＋ Vibe 一句定位）· persona-soul（她自述：我是谁／怎么说话／核心／底线）· AGENTS（互动手册：核心指令／说话风格／性格锚点／对话节奏／禁止做的事／边界）· 外观（一行一条，供 body 标签）。

**料源分层**（高→低，按可信度取）：

1. **角色一手原话**——App 内互动台词库（`台词/<角色>/`）最高：那正是「她对着用户说的话」，与卡要演的形态同构
2. **正文引语**——作品正文里她本人的台词（剧情态，次一等）
3. **声线锚点档**（`故事设定集/速查/速查-<角色>声线锚点.md`）——自称／称谓／句尾／口癖的统计，写 system_prompt 硬规则的直接依据
4. **官方设定档 ＋ 判型案例 ＋ 名场面金句集**——性格内核、逆鳞、关系、可讲的边界

**声线锚点档怎么提**（每角色一次）：

- **跑统计不凭印象**：自称／第二人称／句尾分布／语气助词／感叹号数／高频短语，逐项带条号（例：「自称“我”108 次、0 次用名字；“莉莉”只在起床气档出现 6 条」）。
- **附一张与对照角色的差异表**——同作品里性格相反的两个角色并排一放（尤其双子），写谁都不会漂。
- **分场景差异单列**：同一人不同场合松紧不同（实测：起床气档省略号密度是主页档的 **9 倍**）。
- **卡要演哪一档就取哪一档**：剧情分「过去篇／现在篇」的角色，**卡的常态声线取现在线**，过去篇只当成长弧线的背景（拿早期声线写卡 = 写成了另一个人）。

**没有台词库、只有正文时**：**别用规则抽引语，判归属交给子代理**——第三人称小说里规则两头都错（漏掉前后没点名字的真台词、误收别人的话；实测 238 条引语只筛出 40 条且大半是错的）。派子代理逐篇读、逐条判，任务书要死三样：**每条带行号**、**明确列出哪些行是别人的话**（可复核）、**旁白不算台词**。实测每篇约 20 秒，产出与人工相当。

**卡图／立绘**（PNG 嵌卡用）：官方 API 快照的 `contents[].avatar` 存的是**完整 URL**，可直接取（有的线可从素材 skill 的 API 快照拿：`references/data/characters-api-*.json`）；**中文路径要先 `urllib.parse.quote(u, safe=":/")` 再请求**，直接 `urlopen` 会报 `UnicodeEncodeError`。按旧例存 `<素材根>/images/<作品>-立绘/`，并在卡库 INDEX 的备注里标「待嵌 PNG」。

**本地立绘包是 jpg 时**（老游戏立绘多按「服装＋角色」命名，全 jpg）：`embed_tavern_card.py` 只收 PNG，非 PNG 直接 `raise ValueError("底图不是 PNG")`——先用 PIL 转。转换两版一起给用户挑，别自己定：

```python
im = Image.open(src).convert('RGB')
r = im.resize((400, round(im.height * 400 / im.width)), Image.LANCZOS)  # 等比缩到宽 400
r.crop((0, 0, 400, 600)).save(out_a)   # A 顶部对齐裁 400×600：卡图惯例，头到腿、脚被裁
r.save(out_b)                          # B 400×800 原比：全身不裁，卡图显示更高
```

- **用哪套服装系列由用户定，别自己按「哪套齐」拍**——「齐」只保证凑得够张数，不代表用户要这套（实测：按「公式服 16 个全齐」拍定，用户当场改「用私服，不是公式服」）。挑之前先列各系列覆盖面交给用户选。
- **选定系列后，卡里 `[body= …]` 外观标签必须按 `skins/<系列><角色>.md` 的内容描述表重写**——卡文外观多半来自旧系列或通用设定档，换图不换字＝玩家看到图和描述是两个人（实测：16 张的 body 全是公式服写法，卡图已换私服）。逐条取发色/发型、瞳色、服装主体、配饰，不要凭记忆改。
- **立绘名 ≠ 卡名时建映射表**（如 `私服千姬.jpg` → 卡 `菊理千姬.json`），批量循环按映射取图，别拿卡名硬拼文件名。
- 裁完先 `vision_analyze` 核一遍头有没有被切——立绘构图不一，写死 `(0,0,400,600)` 对某些角色会切到脸。
